## 📌 О проекте

Проект демонстрирует **сквозной пайплайн** прогнозирования операционного денежного потока компании на основе данных о клиентах.

**Гипотеза:** Использование поведенческих клиентских метрик (RFM-сегменты, LTV) в качестве дополнительных признаков позволяет повысить точность прогноза денежного потока по сравнению с моделями, использующими только финансовые временные ряды.

**Что внутри:**

- 🔄 **ETL-пайплайн** — генерация данных, загрузка в SQLite, трансформация
- 🧮 **RFM-анализ** — сегментация клиентской базы через SQL-запросы
- 📊 **Feature Engineering** — создание лаговых признаков и агрегатов
- 🤖 **XGBoost** — обучение модели прогнозирования
- 📈 **Сравнение моделей** — XGBoost с ARIMA и LSTM
- 📉 **Дашборд** — визуализация метрик, графиков и данных (Streamlit)

## Способ 1. Автоматический запуск

1. Скачайте и распакуйте архив с проектом.
2. Дважды кликните по `cashflow_forecoaster.bat` (или `cashflow_forecoaster.ps1` для PowerShell).
3. Дождитесь установки зависимостей (первый запуск может занять более 5 минут).
4. В браузере откроется интерфейс сервиса.
5. На рабочем столе появиться ярлык, далее можно запускать через него (последующие запуски будут около 5-10 секунд).

## 🗄️ Подготовка собственной базы данных (SQLite)

Если вы хотите использовать свои данные вместо синтетических, загрузите SQLite-базу через интерфейс сервиса. База должна содержать три таблицы со строго определённой структурой:

**1. Таблица customers**
| Колонка           | Тип	                | Описание                                   |
|-------------------|---------------------|--------------------------------------------|
| customer_id	      | INTEGER PRIMARY KEY | Уникальный ID клиента                      |
| registration_date | DATE                | Дата регистрации (формат YYYY-MM-DD)       |
| region            | VARCHAR(50)         | Регион (произвольный текст)                |
| segment           | VARCHAR(50)         | Сегмент (например, VIP, Средний, Массовый) |

**2. Таблица transactions**
| Колонка          | Тип                 | Описание                                  |
|------------------|---------------------|-------------------------------------------|
| transaction_id   | INTEGER PRIMARY KEY | Уникальный ID транзакции                  |
| customer_id      | INTEGER             | Внешний ключ к customers.customer_id      |
| transaction_date | DATE                | Дата покупки                              |
| amount           | DECIMAL(10,2)       | Сумма транзакции                          |
| payment_method   | VARCHAR(20)         | Способ оплаты (например, Карта, Наличные) |

**3. Таблица cashflow**
| Колонка       | Тип              | Описание                   |
|---------------|------------------|----------------------------|
| date          | DATE PRIMARY KEY | Дата (уникальная)          |
| total_revenue | DECIMAL(12,2)    | Общая выручка за этот день |

## Пример создания пустой БД через командную строку SQLite:

```bash
sqlite3 my_data.db < sql/schema.sql
```
После этого вы можете импортировать свои CSV-файлы или заполнить таблицы вручную. Затем в приложении выберите файл my_data.db и поставьте галочку «Использовать загруженную БД».

## 📊 Использование приложения

Интерфейс состоит из боковой панели управления (слева) и основной области для отображения результатов.

## Боковая панель (слева)

1. Генерация данных

- Настройте количество клиентов, транзакций и временной период. Нажмите кнопку «Сгенерировать новые данные» – будут созданы синтетические CSV-файлы в папке data/raw/.

2. Загрузка своей БД

- Загрузите SQLite-файл с вашими данными (структура описана выше). После загрузки прожмите галочку «Использовать загруженную БД».

3. Запуск прогноза

- Укажите количество месяцев для тестовой выборки (по умолчанию 6). Нажмите «Запустить прогноз». Приложение:

- Выполнит ETL (создание БД, загрузка данных, RFM-анализ)

- Сформирует признаки (лаг-признаки, агрегации)

- Обучит модель XGBoost

- Сохранит результаты в папку reports/

4. Сравнение моделей

- Нажмите «Запустить сравнение ARIMA | LSTM», чтобы дополнительно обучить ARIMA и LSTM и сравнить их с XGBoost.

5. Сохранение данных

- Укажите имя папки (по умолчанию saved_data_reports) и нажмите «Сохранить данные и результаты» – все папки data/ и reports/ будут скопированы в подпапку с временной меткой.

6. Очистка данных

- Удаляет все сгенерированные данные, БД, отчёты и загруженные файлы. Операция необратима! Предварительно сохраните нужные результаты.

## Основная область (результаты)

- После выполнения прогноза здесь отображаются:

  - Метрики качества (MAE, RMSE, Коэффициент детерминации)

  - Графики важности признаков и сравнения прогноза с фактом

  - Расширенная аналитика – прогноз на следующий месяц, точность, изменение за период, ключевые драйверы

  - Сравнение моделей – таблица и график ошибок для XGBoost, ARIMA, LSTM

  - Просмотр таблиц БД – транзакции, клиенты, денежный поток, RFM-сегменты

  - Справочник признаков – пояснение значений всех колонок в датасете

## 🤔 Чем этот проект отличается от других?

На GitHub есть много проектов по прогнозированию денежных потоков и анализу клиентской базы. Но большинство из них — либо отдельные Jupyter-ноутбуки, либо решают только одну задачу.

Этот проект — первый, который объединяет три ключевые области в одном готовом инженерном решении:

1. Финансовое прогнозирование — Прогноз операционного денежного потока компании
2. Клиентская аналитика — RFM-сегментация, LTV, поведенческие паттерны
3. Машинное обучение — Сравнение XGBoost, ARIMA и LSTM в одном пайплайне

Ключевое отличие от аналогов:

1. Сквозной ETL-пайплайн — от генерации данных до дашборда. Это не набор ноутбуков, а готовый сервис.

2. Сравнение трёх классов моделей — статистическая (ARIMA), градиентный бустинг (XGBoost) и нейросети (LSTM). Вы видите, какая модель лучше для ваших данных.

3. Прямая связь клиентских метрик с прогнозом — RFM-сегменты и LTV используются как признаки для прогноза денежного потока. Это и есть научная гипотеза: поведение клиентов влияет на деньги компании.

4. Готовность к использованию — один клик по cashflow_forecoaster.bat, и приложение запускается. Никакой ручной установки зависимостей.

5. Бизнес-ориентация — цель не просто «построить модель», а дать инструмент финансовому директору для управления ликвидностью.

Для кого этот проект:

1. Для финансовых аналитиков, которые хотят точнее прогнозировать денежные потоки.

2. Для data scientist-ов, которые ищут готовый пример интеграции клиентских данных в финансовые модели.

3. Для студентов и соискателей, которым нужен сильный пет-проект для портфолио.

## ⚠️ Частые проблемы и их решение

1. Антивирус блокирует проект

Если ваш антивирус (особенно Windows Defender) удаляет файлы проекта или блокирует его запуск — это ложное срабатывание.

- Решение: добавьте папку с проектом в исключения антивируса:

  - Откройте Параметры → Конфиденциальность и безопасность → Безопасность Windows.

  - Выберите Защита от вирусов и угроз → Управление настройками.

  - Пролистайте до Исключения → Добавить или удалить исключения.

  - Нажмите Добавить исключение → Папка.

  - Выберите папку cashflow-forecaster.

- Почему это безопасно:

  - Вы исключаете только одну папку с проектом, а не всю систему.

  - Весь код проекта открыт и доступен для проверки в папке src/.

  - Проект использует только официальные библиотеки из PyPI.

2. Ошибка «... was unexpected at this time»

Если при запуске .bat появляется эта ошибка, откройте командную строку в папке проекта и выполните команды вручную:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
streamlit run dashboard/app.py
```

3. TensorFlow не устанавливается

TensorFlow поддерживает Python 3.9–3.11. Если у вас Python 3.12 (она плохо поддерживает), 3.13 или 3.14, установите Python 3.11 дополнительно или удалите строку tensorflow>=2.12.0 из requirements.txt (проект будет работать без LSTM).

- Путь с кириллицей
  - Убедитесь, что папка проекта находится в пути, содержащем только латинские буквы. Кириллица в пути может вызывать ошибки кодировки.

4. Ошибка DLL load failed для TensorFlow

Причина: отсутствует Microsoft Visual C++ Redistributable.

- Решение: установите VC++ Redistributable и перезапустите приложение.

Если есть другие ошибки или решения не помогают пишите на почту автору.
